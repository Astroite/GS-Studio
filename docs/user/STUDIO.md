# GS Studio 桌面

当前桌面使用 Tauri + React，Three.js + Spark 提供交互视口。Rust 管理独立 Python JSONL worker，预处理、训练和原生编辑使用同一共享 Torch 2.8/cu129 环境的不同进程。CLI 与桌面共用操作层和状态规则，详细命令见[工作手册](CURRENT-WORKFLOW.md)。

## 项目与审核

项目树组织 Location、Scene、Capture、Run、Segment、Experiment 和外部导入。状态来自清单、哈希和阶段证据；文件存在不能代表成功。Capture 的源顺序、大小和 SHA256 固定，迁移后须完整重定位校验。

桌面新 Run 要求遮罩审核。逐张明确 ok/exclude 后才固定当前集合；多边形修改产生新的二值遮罩和身份。primary 与 repair 分别审核，身份变化需重新读取，不能重写哈希绕过。QA 同时展示完整性、分段可训练性和路线覆盖，通过一个分段不会自动批准全路线或启动全量。

## 训练与控制

选定分段或外部包后先准备真实训练选项。photo 预设为照片/原始外部 COLMAP：10000 步、SH3、最多 1M 点、seed42、最长边1600、光度/bilateral/depth 请求默认关。gs 用于全景/视频：原尺寸、max(30000,30×训练图数)，辅助请求默认开。quality_v2 与 observed_v5 是冻结配方；observed_v6 实验性，与输入预设分别选择。

深度控制读取核心返回的 available/observations/reason，不可用时禁用并显示原因。请求值不等于有效启用；没有真实锚点不能显示已启用。光度是总开关，bilateral grid 要求同时打开光度。改变输入、配方或覆盖设置需要新实验，源图与可信 split 不原地修改。

| 控制 | 行为 |
| --- | --- |
| pause | 安全步保存并退出，释放 GPU |
| resume | 从同身份 checkpoints/latest.pt 启动新进程 |
| suspend / unpause | 保留进程、显存和锁的热挂起/继续 |
| checkpoint | 立即安全保存并继续 |
| stop | 保存后提前结束，不算成功 |
| cancel | 取消当前 job/generation 并管理其进程树，恢复前核验实际落盘证据 |

控制绑定包哈希和 generation。首次检查点前失败只有显式从零重试才能继续；有检查点时不接受该标记。活动页显示结构化进度和日志，源图/渲染按包身份、请求 ID 与文件哈希配对。预览不训练留出图，也不改变预算。

只有预算完成、评估完成和包/核心/检查点/模型身份一致才显示 succeeded。停止、暂停和退出码零都不足。实际画质与全路线覆盖另行判断；既有全景场景仍有明显伪影。

## 外部输入和选帧

外部 COLMAP 可导入 images、一个 BIN/TXT 模型和可选 masks，或直接使用有效共享包。必须提供完整分组 JSON，或明确确认每图独立；不从文件名猜可信 split。它写独立导入记录，不冒充 Run QA，源输入只读核验。

独立 select-sharp 接收显式 source/out、窗口、候选率和阈值，支持分阶段恢复；只写 out，不创建 Run、不训练。它仍共用 GPU 锁，操作细节见工作手册。

## 视口、编辑和导出

交互浏览使用 Spark；精确非穿透选择与最终编辑验证使用原生渲染/选择。Spark 帧率不能当作训练或原生渲染吞吐量。训练相机使用规范化 RUB 世界/RDF 相机坐标，不能把原始 COLMAP w2c 直接当视口相机。

矩形选择支持穿透/非穿透、反选、清空、删除、撤销/重做。模型编辑保留历史，不改活动训练的参数、源模型或 checkpoint。变换为 position、Euler XYZ 弧度 rotation 和统一 scale；crop 在原模型局部坐标、变换之前应用。界面角度在协议边界转换为弧度。

原生渲染与导出应用相同删除、历史、裁剪和变换；确认变换是一条撤销记录。导出选择新路径，禁止覆盖源模型或训练模型，协方差与 SH 随旋转一致更新。PLY 保留浮点属性；SPZ 有损，超出编码范围的属性会裁切，不能承诺与 PLY 逐像素等同。

10 月 16 日的实际桌面证据覆盖框选、删除/撤销/重做、数值平移、提交/重开与 PLY 导出；手柄、裁剪及 SPZ 的部分证据来自独立 API。不要把 API 结果扩展成全部鼠标交互已验收。本候选版新包的最终结果仍见[迁移记录](../development/PIPELINE-MIGRATION.md)。
