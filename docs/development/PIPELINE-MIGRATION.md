## 既有接受范围

2026-10-16 的代表链路记录覆盖五种输入的代表分段训练、留出评估与 PLY/SPZ 回读，同机 South Building 三次配对回归、中文路径运行、检查点恢复和部分真实桌面编辑。普通照片/视频的固定焦距继承问题修正后，以同一代表图像集合创建新 Run 验证；旧诊断保留。

原始图像、日志、逐视角表、机器路径和个人授权留在仓库外。[归档清单](../archive/source-retirement-20261017.json)记录整理前来源及哈希，[基准汇总](BENCHMARKS.md)保留可公开的方法、结果及负向个例。代表分段通过不证明全路线覆盖，也不证明全景质量已达到目标。

2026-10-17 精简验证的详细表只维护在[运行时瘦身记录](RUNTIME-SLIMMING.md)，避免多处计数不一致。其范围包括：

- CPU 流水线、运行时、前端、Rust、核心和 vendor 测试；核心跳过项单独列出。
- 21 张真实遮罩对照和固定 South Building 112/16 视图、120 步一致性回归。
- 实际精简 local 候选包的封闭 CPU/GPU、保存暂停/恢复、遮罩及探测；独立 public 配置的可选工具缺席检查。
- local-final 逐文件完整性、本地激活、原生窗口及 worker 启动/终止；public 压缩包解压到中文/空格路径后的完整哈希及独立启动。
- 去重本地 SDK 的两帧真实 X6 动态拼接/FlowState，源哈希保持不变。

候选包功能检查、最终包重组装完整性和搬移启动分别绑定各自清单；没有将它们合称为最终包全部重新完成 GPU 或视觉交互验收。120 步短回归不替代 10k 步画质或稳健速度对比。源码 Qt 界面和 Qt 专属测试的归档见[清单](../archive/source-retirement-20261017-002.json)，保留的 native/editor 源码支持模块没有数值改动。

## 已知限制与后续门槛

| 范围 | 限制或所需证据 |
| --- | --- |
| 画质与覆盖 | 全景代表场景质量偏低，有天空、植被、遮挡伪影和覆盖缺口；原因未经消融确认 |
| 配方与 GPU | quality_v2/observed_v5 冻结，observed_v6 实验性；实际 GPU 只验证架构 8.9 |
| 工具与格式 | RealityScan 另装，INSV 外接合法 SDK；SPZ 有损且可能裁切属性范围 |
| 编辑验收 | 既有真实桌面证据覆盖框选/删除/历史/数值平移/PLY，手柄、裁剪与 SPZ 部分来自独立 API；窗口启动不替代视觉/交互 QA |
| 恢复与资源 | 受控故障不等于真实断电或磁盘耗尽；Spark FPS、整卡显存与原生吞吐/进程显存不能混用 |
| 新构建 | 源文件、依赖、扩展或载荷改变后，按[发布说明](WINDOWS-RELEASE.md)选择并记录重新验证范围 |
| 二进制分发 | [第三方证据清单](../distribution/third-party-sources.json)的未闭合项仍阻断上传；运行成功不授予再分发权 |

自有代码 Apache-2.0 不改变第三方条款，包括 GPL `plyfile`。源码检查、历史运行证据、产品质量及第三方分发条件分别评估；源码整理不执行 GPU、训练、重建或安装。
