这些是 2026-10-16 及之前的已记录结果，不是 v0.3.0-rc.1 新目录包的验收。原始运行、参考程序分析、图片、逐视角表和机器路径留在仓库外；来源原文件与 SHA256 见[归档清单](../archive/source-retirement-20261017.json)。没有在本次整理中重新运行训练。

## 可复核的方法

公开 South Building 对照固定 112 个训练视图、16 个留出相机和 10000 步。明确图像哈希、相机/K、场景归一化与 split，再比较相同视角的 RGB8、相同有效像素掩码、PSNR 与 uniform11 SSIM。留出图不参与图像损失或参数拟合；历史核心对照曾共享由完整重建生成的点云及融合颜色，不把它称为完全无留出信息的初始化。

计时必须说明完整 train 调用、恢复段、单内核或日志片段，不能跨范围算加速倍率。配对运行记录每次负向结果，不只报告最佳值。显存区分 Torch allocated/reserved、进程占用和整卡占用；不同口径不相减。记录 seed、预算、配方、依赖/源码/扩展哈希、驱动和硬件。固定开发场景参与配方选择，不能据此声称跨场景泛化或像素等价。

保留的 `engine/scripts/evaluate_reference_pngs.py` 与 `render_reference_cameras.py` 要求显式相机和输入证据，现有测试用合成输入验证其拒绝路径。公共仓库没有附带私有拍摄或专有反汇编。

INSV 注册 358/372 图像、82/84 采样位置，保留 27.995 秒及 44.011 秒覆盖缺口；不是全路线通过。普通视频由固定照片生成，全景视频由已有序列生成；不代表全部实际设备。全景的低分和明显伪影不因完整链路完成而消失。

同机三次 South Building 配对中位变化为 PSNR +0.351531 dB、SSIM +0.00018388、耗时 +3.97418%。第 2 对画质和第 3 对耗时存在单次回退，未从记录排除。该集成回归与上面的代表分段及下方的早期配方试验范围不同。

## v6 未晋升

同一固定场景的第四轮完整调用：v5 控制 R16 为 264.951 s、21.758497 dB / .791290；保守裁剪 R17 为 255.931 s、21.654339 dB / .788512。约 3.4% 的局部时间收益没有同时满足冻结的整体/逐视角画质门槛；R18、R19 也未通过。每组只有一次完整训练，不能据此推断统计等效或一般性提速。quality_v2 与 v5 保持冻结，v6 仍实验性。
