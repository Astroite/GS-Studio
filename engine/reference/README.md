# Public reference notes

The current [behavior contract](../../docs/architecture/ENGINE-CONTRACT.md)
documents the independently authored implementation. Clean
[benchmark methodology and aggregate results](../../docs/development/BENCHMARKS.md)
retain the limits of the recorded measurements.

Raw captures, runtime evidence, proprietary disassembly and one-off analysis
scripts are kept outside the public source repository. Their original relative
paths and SHA256 values are recorded in the
[archive manifest](../../docs/archive/source-retirement-20261017.json).
They are not runtime or current test dependencies. Historical results do not
certify the v0.3.0-rc.1 candidate.
